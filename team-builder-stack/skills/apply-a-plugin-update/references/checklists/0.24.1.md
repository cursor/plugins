# 0.24.1

Changes an existing team needs from this release. Apply a plugin update checks only these items when Plugin version applied is older than 0.24.1 and the installed version is 0.24.1 or newer. A category that says none is not a change. Nothing here is applied without the person's yes.

## Skills this release changes

The plugin install brings these, so there is nothing to apply for them: Delegate work (and its template), Plan the work (and its template), Verify work (Rechecks), Write a workflow skill (its workflow skill reference), Explain how it works (its principles file and guide), Apply a plugin update, and Team Builder operating guide. Delegate work step 2 now holds the long-job rule and the stop rule: a worker writes its result file and ends, and a fix goes to a new worker. A recheck uses a new checker. Plan the work's template matches the skill: a Large plan names Goal and done and Code, and the template has the For a skill line. A workflow skill already in the person's library picks up the Load and Do the work wording only when it is rewritten.
