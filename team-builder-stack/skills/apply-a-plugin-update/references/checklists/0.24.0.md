# 0.24.0

Changes an existing team needs from this release. Apply a plugin update checks only these items when Plugin version applied is older than 0.24.0 and the installed version is 0.24.0 or newer. A category that says none is not a change. Nothing here is applied without the person's yes.

## Skills this release changes

The plugin install brings these, so there is nothing to apply for them: Verify work, Write a workflow skill (steps 3 and 10, its workflow skill reference, and its template skeleton), Plan the work (and its template), Check my bots (steps 3, 4, and 8), Run the weekly bot review (step 3 and the Review part), Clean up memory (its Apply part), Inform manager bot (step 3), Delegate work (step 2), Explain how it works (its principles file and guide), Apply a plugin update, and Team Builder operating guide. Verify work adds Numbers and claims: a figure, a claim that something was filed, sent, or done, a claim that something doesn't exist, and a data pull the person asked for always get a fresh checker, and a labeled self-review or a script check never covers them, except a bot's read-back of its own memory or routines, which is worded as that bot's own report. Write a workflow skill asks whether a skill's deliverable is plan-first. A plan-first skill runs Plan the work before it builds, on every run, scheduled ones included, and Plan the work shows its plan as a plan page and waits for the person's yes. A skill not marked plan-first runs straight through; when an older skill calls Plan the work, it writes no plan and hands back. For a plan-first skill on a schedule, Write a workflow skill asks whether its plan should arrive at a review time and, if so, offers a calendar invite, added only after a yes. Plan the work also plans work no skill covers when the person asks, and Delegate work runs it after a yes. A task left for later names where its completion will show, as `Done when: <what> in <where>`. Check my bots flags once each workflow skill whose Hand off doesn't write that line, and lists each open task missing it from a skill that does. A workflow skill already in the person's library picks up the plan-first question and the Done when line only when it is rewritten.
