Changes an existing team needs from this release. Apply a plugin update checks only these items when Plugin version applied is older than 0.18.0 and the installed version is 0.18.0 or newer. A category that says none is not a change.

## Operating guide layout

In each owner bot operating guide, in the Handoffs section, replace the Owner bot line, word for word, with the Owner bot line in every bot's operating guide reference: When a task finishes, or the person changes one in chat (parks, cancels, moves or rescopes it), I update the task and send the note to my manager bot with Inform manager bot. A block, a decision, a deadline at risk, or a change to today’s brief is sent so it acts on it now. I hand the next step to the bot that owns it, and ask a specialist bot about its topic, with Delegate work. Skip the line when it already says that.

Team Builder gets its operating guide from the plugin. Do not edit a library copy of that guide. The plugin copy already says, under Keeping this guide current, that the scheduled run drafts the review pack and the decision list to a dated file, posts the summary and the Needs you items in the chat with the person, and does not wait for an answer. Memory reports wait until the person replies to the summary in the chat. Applying changes waits until the person says yes in the chat.

## Team spec layout

Add a Runs per week line after Trigger in each routine block. Count it from that routine's trigger, such as 5 for once each weekday, or about how many for an event trigger and where the number came from. Fill it in after the person's yes. Each routine run spends usage, so a routine that runs often spends more than one that runs rarely. A test run also spends usage.
