# 0.22.0

Changes an existing team needs from this release. Apply a plugin update checks only these items when Plugin version applied is older than 0.22.0 and the installed version is 0.22.0 or newer. A category that says none is not a change. Nothing here is applied without the person's yes.

## Skills this release changes

The plugin install brings these, so there is nothing to apply for them: Build a bot, Check my bots, Coach my bots, Clean up memory, Set up Team Builder, Verify work, Write a workflow skill, Build my team, Apply a plugin update, and Team Builder operating guide. Build a bot, Set up Team Builder and Clean up memory now save setup facts as profile facts. A bot made from a bot template can arrive with memories: Build a bot has it list them and drop any that belong to another unit after the person's yes, and Check my bots flags one that still holds another unit's memories. Each skill that writes a routine into the spec adds its Delivers to line, as the blank team spec defines it. Verify work gives the fresh checker each skill it must follow by its path as well as its name. Build a bot's setup message reads as short steps, with the same rules.

## Team spec layout

Each routine block names who its runs deliver to. After the person's yes, in the team spec at `/workspace/team-builder-stack/team-spec.md`, under Routines, add a `Delivers to:` line after Skill and above Prompt in each routine block. Fill it in as the Routines note in the [blank team spec](../../../build-my-team/references/team-spec-template.md#routines) defines it. For Team Builder: Weekly review prep, write `the person, in their chat with Team Builder`. Skip a block that already has one. Never put it inside the prompt.
