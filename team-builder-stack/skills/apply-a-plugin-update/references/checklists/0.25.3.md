# 0.25.3

Changes an existing team needs from this release. Apply a plugin update checks only these items when Plugin version applied is older than 0.25.3 and the installed version is 0.25.3 or newer. A category that says none is not a change. Nothing here is applied without the person's yes.

## Skills this release changes

The plugin install brings these, so there is nothing to apply for them: Build my team, Apply a plugin update, and Team Builder operating guide. The team map now builds when Who verifies says none, and the team map check lists a Who verifies line that names no specialist or manager bot under Your team. The team map check also accepts Hands to: none with a reason, as the workflow skill template documents.

## Team spec layout
