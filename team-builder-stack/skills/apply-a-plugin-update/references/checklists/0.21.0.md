# 0.21.0

Changes an existing team needs from this release. Apply a plugin update checks only these items when Plugin version applied is older than 0.21.0 and the installed version is 0.21.0 or newer. A category that says none is not a change. Nothing here is applied without the person's yes.

## Skills this release changes

The plugin install brings these, so there is nothing to apply for them: Build my team (step 9, step 11, its blank team spec, and its team map files), Check my bots (step 9), Build a bot (step 13), Retire a bot (step 7), Set up Team Builder (step 8), Apply a plugin update, and Team Builder operating guide. The team map now draws each bot with its own shape and color, and shows a picture for a bot when the person gives one. Each of those steps that saves a changed spec after the person's yes records each bot's look on its empty Shape and Color lines first, so a later rebuild moves no look.

## Team spec layout

The new lines are optional and additive. A spec without them still builds, and the map picks each bot's shape and color from its id. After the person's yes, in the team spec at `/workspace/team-builder-stack/team-spec.md`, under Your team, add these three lines after Connectors in each bot block, and fill in only what the person gives:

- `Shape:` circle, square, hexagon, capsule, leaf, or drop, or empty.
- `Color:` a six-digit hex color, or empty.
- `Picture:` the path to a picture of that bot on the computer the bots share, or empty.

Skip a block that already has them, and leave a block's lines out when the person says no. Then, after the same yes, record the looks the map shows today: run the look step in [Record the looks](../../../build-my-team/references/team-map/README.md#record-the-looks) on the spec, with no current spec. It fills each empty Shape and Color line with the bot's current look and keeps every look the person set. Then rebuild the team map.
