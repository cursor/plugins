# 0.25.2

Changes an existing team needs from this release. Apply a plugin update checks only these items when Plugin version applied is older than 0.25.2 and the installed version is 0.25.2 or newer. A category that says none is not a change. Nothing here is applied without the person's yes.

## Skills this release changes

The plugin install brings these, so there is nothing to apply for them: Build a bot, Build my team, Check my bots, Clean up memory, Coach my bots, Delegate work, Explain how it works, Plan the work, Retire a bot, Run the weekly bot review, Save what we learned, Set up Team Builder, Verify work, Write a workflow skill, Apply a plugin update, and Team Builder operating guide. This release is a wording fix: the skills now describe only what a person sees and does in Grok Bot. The shared rules and the profile fact templates in every bot's operating guide do not change; Team Builder's own profile fact 3 does, as Profile facts says.

## Shared rules

None.

## Operating guide layout

After the person's yes, in each bot type's operating guide in their skill library, replace the sentence under the type line that starts "Read this guide at the start of every task" with: "Read this guide at the start of every task, and again whenever you pick work back up." Leave the rest of that paragraph as it is.

## Profile facts

After the person's yes, Team Builder replaces its profile fact 3 with fact 3 from its [profile](../../../set-up-team-builder/references/team-builder/profile.md): "3. Before any task, I Read my operating guide skill, team-builder-operating-guide, and follow it." It names fact 3 by its number and current text as the one it replaces, and reads the saved fact back by its exact text. Other bots' profile facts do not change.

## Routine form

None.

## Team spec layout

After the person's yes, in the team spec at `/workspace/team-builder-stack/team-spec.md`, under Records and logs, rename the team map line ending in `id:` to `- Team map Page:` and keep its value. A spec that still has the old line builds the same map.
