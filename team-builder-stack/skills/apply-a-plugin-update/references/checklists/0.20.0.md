# 0.20.0

Changes an existing team needs from this release. Apply a plugin update checks only these items when Plugin version applied is older than 0.20.0 and the installed version is 0.20.0 or newer. A category that says none is not a change. Nothing here is applied without the person's yes.

## Skills this release changes

The plugin install brings these, so there is nothing to apply for them: Inform manager bot (and its template), Delegate work, Write a workflow skill (its workflow skill reference), Build a bot (steps 8 and 9 and its operating guide reference), Check my bots, Explain how it works (its principles file and guide), Apply a plugin update, and Team Builder operating guide. Inform manager bot adds a note for a check the manager bot asked a bot to run, such as reading what a meeting decided once it ends. That note is sent even when nothing changed and even on delegated work, and asks the manager bot to act now only when the result changes today's brief or leaves a block. Every place that lists when Inform manager bot runs now names that check too. A workflow skill already in the person's library picks up the matching Hand off line only when it is rewritten.

## Operating guide layout

In each owner bot operating guide, in the Handoffs section, replace the Owner bot line, word for word, with the Owner bot line in every bot's operating guide reference: When a task finishes, the person changes one in chat (parks, cancels, moves or rescopes it), or a check my manager bot asked for ends, I update the task list and send the note to my manager bot with Inform manager bot. A block, a decision, a deadline at risk, or a change to today’s brief is sent so it acts on it now. I hand the next step to the bot that owns it, and ask a specialist bot about its topic, with Delegate work. Skip the line when it already says that. Make this change only after the person's yes.

The other lines under Who tells whom don't change. Team Builder gets its operating guide from the plugin, so there is nothing to apply for it.
