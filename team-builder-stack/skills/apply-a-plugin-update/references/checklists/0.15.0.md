# 0.15.0

Changes an existing team needs from this release. Apply a plugin update checks only these items when Plugin version applied is older than 0.15.0 and the installed version is 0.15.0 or newer. A category that says none is not a change.

## Shared rules

Add this rule, word for word, to the shared rules in every bot type's operating guide:

- I save facts about my unit of work, and preferences I learn while doing the work, to my own memory without asking. That does not go through Team Builder. I never decide a change to how I work: my skills, my operating guide, my routines, or a standing rule about how I do the job. When one of those should change, I tell Team Builder with Inform Team Builder. I save such a change only when Team Builder sends it after your yes.

Team Builder's own guide ships this rule and keeps its own way of changing itself through the plugin. Do not edit a library copy of a Team Builder skill. Offer to rename that copy. Skip the rename offer when Plugin delivery says synced into the library by the plugin maintainer; there the copies are how every bot reads them.

## Operating guide layout

The five sections stay in this order: Job, Skills, Connectors, Rules, Handoffs. Add no section.

Each bot type's Skills section names Inform Team Builder, for when that bot's own skill, operating guide, routine, or a standing rule about how it does the job should change.

## Profile facts

None.

## Routine form

None. A routine prompt stays one sentence: Read the operating guide and follow it, then run one named skill. Do not put steps in the prompt.

## Team spec layout

- On the Team Builder block, add `Plugin version applied`. Leave it blank until Apply a plugin update records the version it applied.
- Under Your team, add optional `Plugin maintainer`. Leave it empty until the person names who maintains this plugin for them.
- Under Your team, next to Plugin maintainer, add `Plugin delivery`. Write `installed`, or `synced into the library by the plugin maintainer`. Installed is the default. Synced means there is no plugin install, and the maintainer copies the stack skills into the person's library. Those copies are how every bot reads them.
- Add a Routines section. For each bot, one block per live routine, with the trigger and the full prompt text, copied from the live routine. Do not invent a routine, and do not change the live routine for this release.
- On Team Builder's Skills line, include `apply-a-plugin-update` and `inform-team-builder`.
