## Routine form

On each routine block, add Skill, the one skill that routine runs. Add Relayed by when another bot's routine triggers it. Otherwise write none and the reason, or leave the line out. Trigger stays the schedule. Prompt stays the full prompt. Do not put the schedule in a skill.

## Team spec layout

- Each handoff gains Waits: whether the sender waits, and for what, or no and why. A handoff may end at You or Every bot.
- Each bot block gains Connectors. Write the connectors that bot uses, or none and why.
- Each system of record may gain How to read: which tool to use and the known pitfalls, or no connector.
- Workflow skill step fields are not applied by this skill. Coach my bots fills Does, Pulls from, Uses, Produces, Hands to, and Needs your review on each workflow skill, then runs the check. A blank field is written none, with the reason. Do not guess a missing fact.
- Plugin version applied and Plugin maintainer stay as they are.
