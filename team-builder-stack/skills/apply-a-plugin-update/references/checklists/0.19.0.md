# 0.19.0

Changes an existing team needs from this release. Apply a plugin update checks only these items when Plugin version applied is older than 0.19.0 and the installed version is 0.19.0 or newer. A category that says none is not a change. Nothing here is applied without the person's yes.

## Skills this release changes

The plugin install brings these, so there is nothing to apply for them: Verify work, Explain how it works (its principles file and guide), Write a workflow skill, Clean up memory, Run the weekly bot review, Plan the work, Build a bot (its operating guide reference), Apply a plugin update, and Team Builder operating guide. Verify work adds When a fresh checker isn't needed, which says when a script check or a labeled self-review is allowed instead of a fresh checker.

## Shared rules

In the first shared rule of every bot type's operating guide, replace the second sentence, word for word.

Current: Every check runs through Verify work, which starts a fresh checker or sends the check to the bot under Who verifies in the team spec.

Proposed: Every check runs through Verify work, which starts a fresh checker, or uses a script or a labeled self-review where it allows one, or sends the check to the bot under Who verifies in the team spec.

The rest of that rule stays as it is. Team Builder's own guide ships this sentence with the plugin.
