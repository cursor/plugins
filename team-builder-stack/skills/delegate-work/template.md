# Delegate work: the template

The three shapes Delegate work writes. Fill every slot marked with angle brackets, and send links to the record, not copies of it.

## A message to a subagent

```markdown
**Read first.** <the name of the skill this work comes from, and of the bot's operating guide>. Read them before you start; you don't share my memory.
**Your piece.** <one unit, one source, one item, or one point of view>
**Your material.** <the piece's ID, and links to only this piece's sources; for a fix, the earlier result file and the reason it failed>
**What to do.** <the step's name in that skill, and the stage's brief, the same for every worker in the stage>
**Return.** <the contract's output fields, each finding with a link to its source>
**Result file.** <this piece's result file in the run folder>
**Done when.** <the contract's done test>. If you can't finish, write "not covered" and what stopped you. Don't guess. <the stop rule from Delegate work step 2>
```

## A handoff message

```markdown
**To <the bot that owns the next step>.**
**Done.** <what's finished, with links>
**Next.** <what they should do>
**What you need.** <links to the record>
**Needed by.** <when>
```

## A combined result

```markdown
**<unit>, <number> pieces run side by side.**
- <piece>: <finding> (<link>)
- <piece>: <finding> (<link>)

<All returned, or which piece failed and why.> <Any conflict, and the source that settles it.>
```
