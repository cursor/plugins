# The Team Builder Stack guide

Find what carries its own history and give each one a bot. Turn each repeated workflow into a skill. Write everything to a record, keep the decisions with people, and check with fresh eyes.

This guide teaches the Team Builder Stack in six short chapters. Chapters 1 and 2 are Basics: enough to build and run one owner bot. Chapters 3 to 6 are Going further: the utility and standard skills, the system map, how a team grows, and how to make the stack yours.

1. [The core idea](01-the-core-idea.md). Give a bot to what carries its own history, and turn each repeated workflow into a skill. (Basics)
2. [Your first owner bot](02-your-first-owner-bot.md). One owner bot for one unit, proved by hand, then put on a routine. (Basics)
3. [Utility and standard skills](03-utility-skills.md). Eight utility skills every bot uses, the standard skills every skill follows, and where each one lives in the stack. (Going further)
4. [The system map](04-the-system-map.md). Where the tailoring lives: your systems, how they store data, and how they tie to your units. (Going further)
5. [Growing the team](05-growing-the-team.md). Manager, owner, and specialist bots, how they work together, and adding bots as the work grows. (Going further)
6. [Making it yours](06-making-it-yours.md). Teach the stack how you work, and keep your skills current. (Going further)

Read the chapters in order the first time. After that, each one stands alone.
