# Triage work: the template

The list triage sends the person, so they read one message instead of every item. Fill every slot marked with angle brackets.

```markdown
**<when>: <number> items.**
- <the item, in one line>. <Where it went: a skill on this bot, the bot that owns it, or for you, with the reason.>
- <the item, in one line>. <Where it went.>

**For you.** <The items that need your decision. For any item no one owns, what I'd need to know to place it next time.>
```
