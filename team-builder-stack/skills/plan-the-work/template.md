# Plan the work: the template

The two shapes Plan the work writes. Fill every slot marked with angle brackets. A Small plan is the first line only.

## A plan

```markdown
**Plan: <Small, Large, or Ask first>.** <why this size, and the pieces for a Small plan>
- Goal and done: <what finished looks like, from the skill's What good looks like>
- Stages: <in order; what runs side by side, what waits>
- Subagents: <per stage: how many, at most 4 at once, in how many waves>
- Run folder: /workspace/team-builder-stack/runs/<skill>/<unit ID>/<date and time>/
- Checks: <Verify work after which stages, one check per separate thing>
- Judge: <none, or Run review panel with the person's ok>
- Stop rules: <one fix per failed piece, at most 2 rounds; not covered, never guessed; a source down means ask, or note it>
- Departures: <what differs from the skill's pattern, and why, or none>
```

## A worker contract, one per stage

```markdown
**Stage <n> contract.**
- Read first: <catalog path of the skill, and of the bot's operating guide>; step: <step name>
- Brief: <the same for every subagent in this stage>
- Input: <only this piece's ID and links>
- Output fields: <field>, <field>, source link, not covered reason
- Write to: <run folder>/<piece>.md
- Done test: <every field filled and every finding linked, or not covered with the reason>
```
