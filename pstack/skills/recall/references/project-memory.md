# Shared project memory

Use `.pstack/memory.md` at the target repository root for decisions and lessons teammates should be able to find in a later session. Read the existing file first. Each entry has a short heading, date, decision or lesson, rationale, and a source such as an ADR, issue, PR, or repository path.

- **Save** a durable lesson from the named topic. Update an existing entry if it covers the same decision. Link to an existing ADR or project instruction when it already holds the details. Keep secrets, personal details, and transient status out of shared memory. Report the entry and its path.
- **Recall** entries relevant to the current request. Cite the entry and check whether its source and the current code still support it. Flag uncertainty if the record is incomplete.
- **Clean** duplicate or stale entries whose replacements or invalidation can be verified. Preserve entries with unresolved status and report what needs review.
