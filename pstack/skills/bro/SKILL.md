Restate your last message. Stop using jargon and speak coherently. State it more simply and concisely, like one human talking to another. Then always end with a clearly labeled "Decisions for you" list: every decision the user needs to make and anything blocking progress, one line each. If there are none, say "Decisions for you: none."
