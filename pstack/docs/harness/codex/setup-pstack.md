# Setup pstack in Codex

Use the current session's model and reasoning settings by default. When the user requests specific role settings, check which models and efforts the current delegation tool supports. Use the available selections for the current task and explain which requested settings are unavailable.

Apply these rules when giving setup advice from poteto-help. Keep role settings in the current task context.
