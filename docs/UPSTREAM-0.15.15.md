## Behavior changes

- Code roles and tooling reflection default to the fast class. Judgment and the hardest tasks remain deep.
- Default review and design panels contain two entries. Explicit user rosters retain their width.
- Setup preserves role overrides, removes retired roles, and requests supported reasoning effort through the optional budget comment. Removing that comment uses host defaults.
- Fresh delegates take each new task unless existing process or checkout state is needed.
- Program audits run hourly through a supported host scheduler. The plan checker accepts confirmed worker model names.
- Added benchmark-checklist, correct, poteto-help, and principle-explain-the-number.
