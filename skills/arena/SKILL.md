# Arena

Read [the core](../../docs/core.md) and the current client adapter.
Keep a checklist: Frame, Candidates, Judge, Pick, Graft, Verify.

## Frame

Define the artifact and 3-6 measurable rubric criteria. Resolve the review role
for a requested multi-model candidate panel. Strict cross-family execution
requires two known distinct families before launch. Do not duplicate a missing
seat. An explicitly approved independent-unverified panel carries no diversity claim.

## Candidates

Give each runner the same goal, inputs, scope, stop condition, and verification
contract. Separate concurrent writers into worktrees with the exact revision
and scoped input patch. Stay within maxWorkers and maxConcurrent. If isolation
is unavailable, serialize candidates. A required missing candidate blocks comparison.

## Judge

Read completed candidates before judging. Use an independent restricted reader
only when justified. If a cross-family judge is required, verify its family
against the known parent/candidate family; unknown parent metadata blocks that
claim. Make a missing optional judge explicit, without inventing its verdict.

## Pick and graft

Score each criterion. Prefer a coherent small interface a future contributor
can extend safely. Read disagreement before deciding. Port only improvements
that fit the selected design. Reframe under-specified divergent candidates
rather than averaging incompatible shapes.

## Verify and output

Run focused project checks and required observable verification on the synthesized
artifact. Return the selected base, criteria, each graft and its source, rejected
alternatives, dropouts, judge status, actual/unknown models, and verification.
